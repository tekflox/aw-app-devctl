# DevCtl

DevCtl adds developer control tools to an AW Workspace. It helps users and agents observe a browser, drive browser actions, and evaluate code in controlled workspace contexts.

## What It Does

- Provides browser control actions such as navigation, clicking, typing, scrolling, screenshots, and script evaluation.
- Adds a developer toggle to the workspace navigation.
- Relays selected actions into the user's active browser tab when enabled.
- Exposes agent-friendly controls for browser-driven debugging and validation.

## Why Use It

Use this app when a development task needs direct interaction with a live browser or workspace tab. It is useful for UI debugging, checking page state, reproducing user flows, and letting agents operate a browser while keeping the user in control.

## How To Use It

Install the app and open the developer control entry from the workspace navigation. Use it with Browser for piloted browsing, screenshots, and page actions. Enable the tab relay only when you want the workspace to interact with your active browser tab.

## What It Delivers

The app gives developers and agents a practical control surface for browser-based work. It makes inspection and interaction faster without requiring a separate debugging setup.
